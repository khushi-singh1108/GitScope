# GitScope

GitScope is an AI-powered platform that helps developers understand GitHub repositories and contribute to open-source projects.

Users can analyze repositories, understand project architecture, analyze GitHub issues, discover beginner-friendly issues, and receive AI-generated contribution guidance.

Main features:

- Repository Analysis
- Issue Analysis
- Explore Trending Repositories
- Good First Issues
- Search GitHub Issues
- Dashboard with Analysis History
- GitHub OAuth Login
- Email OTP Authentication
- Redis Caching
